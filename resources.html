MTH 335
  • An ordinary differential equation with solution $y(x)$ is linear if it can be written as $$\sum_{i=0}^n a_i(x)y^{(i)}=g(x)$$
  • A partial differential equation with solution $u(x_1,x_2,...,x_n)$ is linear if it can be written as $$\sum_{i=0}^n a_i(x_1,x_2,...,x_n) \frac{\partial^i u}{\partial x_1^{b_{1,i}} \partial x_2^{b_{2,i}} ... \partial x_n^{b_{n,i}}}=g(x_1,x_2,...,x_n)$$ where $\forall i=0,1,2,...,n$, $\sum_{j=1}^n b_{j,i} = i$. If this is too messy, so long as you're not multiplying derivatives together or taking sines/cosines of $u$ and any derivative of $u$, it will probably be linear. Manipulate the equation if you're ever unsure!
